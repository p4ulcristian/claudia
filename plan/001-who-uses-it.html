1 · Who uses it

A · You, on your desktop + Claude Code runs underneath on your subscription: no extra bill + Claude can read files, run commands, search the web, as now + chats are Claude Code sessions: history and resume already exist − only works where you are logged in to Claude − subscription usage limits apply
B · Others too (team, public) + anyone with a login can use it − needs an API key: every message is billed − tools, storage and history all built by us − a subscription can't be shared with others
